# Flagstone website

Public site for Flagstone by Monaidea, served by GitHub Pages from `main` at https://flagstone.monaidea.com (custom domain in `CNAME`; the owner creates the DNS record). Same look as https://ledgerstone.monaidea.com (repo VestaNabu-LLC/ledgerstone-site): `style.css` and `site.js` are copies of that site's files, with a few Flagstone additions at the end of `style.css`.

Flagstone is in development (repo VestaNabu-LLC/flagstone, its `CLAUDE.md` holds the rules). Until the owner decides otherwise, the site says "in development", shows no price and no store link, and has no privacy policy page. Each feature card says **Built** or **Coming**; keep those true to the app's `SPEC.md` and the Done items in its `owner/requests.md`. Never claim something the app does not do yet. VestaNabu LLC appears only in the copyright line.
