# Flagstone website

Public site for Flagstone by Monaidea, served by GitHub Pages from `main` at https://flagstone.monaidea.com (custom domain in `CNAME`; the owner creates the DNS record). Same look as https://ledgerstone.monaidea.com (repo VestaNabu-LLC/ledgerstone-site): `style.css` and `site.js` are copies of that site's files, with a few Flagstone additions at the end of `style.css`.

Flagstone is on the Atlassian Marketplace (approved by Atlassian; owner, 2026-11-05): https://marketplace.atlassian.com/plugins/com.vestanabu.flagstone/cloud/overview. Its rules are in VestaNabu-LLC/flagstone, `CLAUDE.md`. Keep every page true to the app's `SPEC.md` and its Done items; never claim something the app does not do. VestaNabu LLC appears only in the legal lines.

Contact form (owner request, 2026-11-02): `/support/` has the same form as https://www.monaidea.com, and the site's other calls to action link to it (`/support/#contact`, with `?topic=reminders-request` and similar to preselect a topic). `contact.js` is a copy of the file in VestaNabu-LLC/monaidea; keep the three copies (monaidea, ledgerstone-site, flagstone-site) identical and bump `?v=` on its script tag when it changes. The form posts to Monaidea's contact Worker at https://forms.monaidea.com (source and tests in the monaidea repo's `worker/`), which checks Cloudflare Turnstile and emails support@monaidea.com through Postmark; `data-product` on the form puts the app's name in the email's subject.
